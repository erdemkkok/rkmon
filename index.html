rkmon APT repository

Hızlı kurulum:

curl -fsSL https://erdemkkok.github.io/rkmon/install.sh | sudo sh

Elle kurulum:

curl -fsSL https://erdemkkok.github.io/rkmon/rkmon.gpg | sudo tee /usr/share/keyrings/rkmon.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/rkmon.gpg] https://erdemkkok.github.io/rkmon stable main" | sudo tee /etc/apt/sources.list.d/rkmon.list
sudo apt update && sudo apt install rkmon
